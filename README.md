# Portfolio

Makuo Okoene, machine learning and applied AI. Built with Vite, React and Three.js (react-three-fiber).

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
npm run preview  # serve the production build
```

- `src/components/Hero.jsx`: particle name (Three.js) and kinetic headline
- `src/components/Chat.jsx`: the About section as a chat
- `src/components/Work.jsx`, `FractonFlow.jsx`: sticky project stage and the Fracton pipeline demo
- `src/components/Skills.jsx`: floating skill bubbles
- `legacy/index.html`: the previous single-file site, kept for reference
- `public/media/`: project videos and posters

Respects `prefers-reduced-motion`. French by default, with an EN toggle.
